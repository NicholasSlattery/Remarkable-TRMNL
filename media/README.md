# Media kit

Narrative and outreach material for TRMNL for reMarkable Paper Pro. Everything here is
prose, not code — nothing in this folder is built, shipped, or read by the app.

| File | What it is |
|---|---|
| [PITCH.md](PITCH.md) | The full pitch: problem, solution, safety story, audience, differentiation, limitations, channel-ready copy, asset shot list, FAQ |
| [DEEP_RESEARCH_PROMPT.md](DEEP_RESEARCH_PROMPT.md) | A standalone prompt for a deep-research tool, asking how alike TRMNL and reMarkable really are as low-distraction devices and how useful the pairing would be |
| [RESEARCH_FINDINGS.md](RESEARCH_FINDINGS.md) | What that research returned, annotated — what to accept, what's wrong and why, and the open actions |

Related project documents:

- [`../LAUNCH.md`](../LAUNCH.md) — canonical listing copy, required disclosures, and the
  advertising gate
- [`../RELEASE_CHECKLIST.md`](../RELEASE_CHECKLIST.md) — blocking items; nothing here may
  be published as "released" until these are complete
- [`../COMPATIBILITY.md`](../COMPATIBILITY.md) — supported models and firmware, so no
  claim here outruns what's validated

## Rules for anything in this folder

- Always carry the disclosure: unofficial community software, not affiliated with TRMNL
  or reMarkable, requires Developer Mode (factory reset, reduced security), hosted use
  requires a BYOD license.
- Link the GitHub Release, never a direct executable — people should see checksums,
  requirements, and known limitations before a download button.
- Never claim real-cloud color, automatic rotation, signed-publisher status, firmware
  support, or battery duration beyond collected evidence.
- Screenshots must be real v2.0 UI on exact-release hardware, with no private data,
  fingerprints, or passwords visible.
- `BYOD_SETUP.md` uses a direct non-affiliate product link. Do not add tracking
  without an explicit commission disclosure.
