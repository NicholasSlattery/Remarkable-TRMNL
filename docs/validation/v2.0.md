The redesigned installer retains localhost-only binding, CSRF protection,
security headers, model/firmware gates, SSH fingerprint confirmation, payload
hash verification, recovery, uninstall, and purge controls. Its inline
JavaScript passes a syntax check; all JavaScript element references resolve to
unique HTML IDs.

## Live power findings incorporated into v2.0

Physical inspection of the connected Paper Pro confirmed deep suspend is
selected, RTC wake is enabled, Wi-Fi power saving is on, and the TRMNL
frontlight setting is 0%. The device journal recorded RTC wake followed by a
return to deep suspend about five seconds later. The prior battery-test data
contained multiple charging periods, which v1.1 incorrectly included in its
projection; v2.0 invalidates such tests and waits for a 10% discharge before
estimating runtime.

## Known release limitations

- The Windows signature is self-signed rather than chained to a publicly trusted
  code-signing authority. It detects post-signing modification but does not
  remove Unknown Publisher or SmartScreen warnings on other computers.
- GitHub CI/CodeQL and artifact attestation can only complete after the tagged
  commit is pushed.
- Real hosted-cloud color output remains dependent on the active TRMNL plugin;
  the physical color pipeline was previously validated with compatible content.
- A multi-day v2.0 battery-runtime result cannot be manufactured during release
  packaging and must be collected with an uninterrupted, unplugged test.
